# Tic Tac Toe

A simple Tic Tac Toe game built with Python and PySide6.

## Features

* Two-player gameplay
* X and O turns
* Automatic winner detection
* Draw detection
* Restart the game
* Turn changes after restarting

## Technologies

* Python
* PySide6
* Qt Designer

## How to Run

```bash
pip install PySide6
python main.py
```
